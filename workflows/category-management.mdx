## Add Category

1. Click **New Category**
2. Enter Category Name
3. Add Description
4. Select Status (Active / Inactive)
5. Click Save

### DDIM-AI Integration
Each Category may contain:
- Knowledge domains  
- Applicable safety/technical standards  
- Difficulty scale (Basic → Intermediate → Expert)

This allows RMS to map categories into the DDIM knowledge framework.

---

## Add Sub Category

A Sub Category defines a role cluster and serves as the main layer where DDIM knowledge is stored.

Steps:
1. Inside a Category, click **Add Sub Category**
2. Enter:
   - Name  
   - Description  
   - Total Experience  
3. Save

### DDIM-AI Integration
Each Sub Category may include:
- Primary objective  
- Core responsibilities  
- Coverage areas  
- Interfaces  
- Competence requirements  
- Certifications  
- Key standards  
- KPIs  

### DDIM Levels Supported:
- Level 1: Fundamentals  
- Level 2: Applied and Scenario Questions  
- Level 3: Expert Diagnostic Questions  
- Level 4: Case-Based and Incident Questions  
- Level 5: Behavioral Competencies (C1–C15)

This powers:
- JD auto-generation  
- AI-based evaluation  
- Interview preparation  
- Competency scoring  

---

## Add Sub Sub Category

Sub Sub Categories define deeper specializations.

Steps:
1. Inside a Sub Category, click **Add Sub Sub Category**
2. Enter:
   - Name  
   - Description  
   - Total Experience  
   - Target Companies  
3. Save

### DDIM-AI Integration
Sub Sub Categories may inherit or extend:
- Knowledge domains  
- Competencies  
- Scenario-based questions  
- Behavioral expectations  

---

## Edit Category

Admins can update:
- Category name  
- Description  
- Status  
- Sub Category details  
- Sub Sub Category details  
- DDIM knowledge levels  
- Behavioral competency matrix  

Changes sync across JD creation and evaluation workflows.

---

## View Category

Viewing a category displays:
- Full hierarchy  
- Sub Categories and Sub Sub Categories  
- DDIM Knowledge Universe (Levels 1–5)  
- Behavioral Competency Matrix (C1–C15)  
- Standards, KPIs, responsibilities, competencies  
- Target companies  

---

## Delete Category

1. Click **Delete**
2. Confirm deletion
3. The Category and its DDIM metadata are removed from RMS

---

## DDIM-AI Integration Summary

DDIM transforms Category Management into a role intelligence engine by attaching:

- Structured question banks (Levels 1–5)  
- Behavioral competencies (C1–C15)  
- Standards and KPIs  
- Role objectives and responsibilities  
- Competence and certification requirements  
- Coverage areas and interfaces  

This ensures JD creation, candidate evaluation, and profile articulation are accurate, standardized, and AI-ready.

---

## Summary

Category Management allows administrators to build a complete job taxonomy:

- Category → Role domain  
- Sub Category → Role cluster enriched with DDIM knowledge  
- Sub Sub Category → Specialization with target companies  

DDIM-AI ensures each role has:
- Clear purpose  
- Defined responsibilities  
- Competency structure  
- Knowledge universe  
- Behavioral competency framework  

This structure powers JD creation, search, matching, evaluation, and AI-driven decision-making across the RMS.
