# Workflow Overview

The Position Allocation workflow defines **which recruiter owns which job roles**.

This workflow directly controls:

- Job visibility
- Campaign access
- Candidate ownership


## Add Position Allocation

1. Open **Position Allocation**
2. Click **Add Allocation**
3. Select:
   - Category
   - Sub-Category
   - Recruiter
4. Save allocation

Recruiter is now responsible for jobs under those roles

![Image](/images/image-1.png)

## View Allocation

1. Click **View**
2. See:
   - Category & sub-category
   - Assigned recruiter
   - Status and timestamps

![Image](/images/image-2.png)

## Edit Allocation

1. Click **Edit**
2. Change:
   - Recruiter
   - Category or sub-category
3. Save changes

Updates apply immediately across recruiter views

![Image](/images/image-3.png)

## Delete Allocation

1. Click **Delete**
2. Confirm action

- Allocation is deactivated (soft delete)
- Recruiter loses access to those job roles

![Image](/images/image-4.png)

## Recruiter Experience Flow

1. Recruiter logs in
2. System fetches **My Allocations**
3. Recruiter can only see:
   - Jobs
   - Campaigns
   - Candidates

linked to assigned categories and sub-categories

## Search & Filter

Admins and managers can filter allocations by:

- Recruiter name
- Category
- Sub-category

Recruiters automatically see **only their own allocations**.

![Image](/images/image-5.png)

## Where It Is Used

- Recruiter job listing visibility
- Campaign access control
- Candidate tracker filtering
- Recruiter dashboards

## Summary

The **Position Allocation workflow** ensures recruiters focus only on relevant job roles, eliminates overlap, and enforces structured ownership across the recruitment lifecycle.

This module is critical for scaling recruitment teams while maintaining clarity, control, and accountability.
